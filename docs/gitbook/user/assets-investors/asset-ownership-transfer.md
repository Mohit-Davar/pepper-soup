# Asset Ownership Transfer

## Asset Ownership Transfer

Asset ownership transfer supports real-time loan transfers to external investors.

| Field | Type | Source |
| --- | --- | --- |
| External owner ID | TEXT, optional | Loan_externalisation table external_owner_id column |
| Settlement date | Date | Loan_externalisation table settlement date column |
| Purchase price ratio | String | m_external_asset_owner_transfer.purchase_price_ratio |

See also: [Asset Externalization: Asset Externalization](asset-externalization.md#asset-externalization).

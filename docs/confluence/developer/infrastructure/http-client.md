# HTTP Client Library

The fineract-client module provides a generated OpenAPI Feign SDK for communicating with the Fineract backend. OpenAPI generation produces the model classes, service APIs, and Feign library, using Feign Apache HttpClient as the HTTP client implementation. The SDK exposes the same APIs and parameter list as existing solutions and uses the same request and response models.

| Component | Description |
| --- | --- |
| Module | fineract-client / feign SDK |
| Generator | OpenAPI |
| HTTP client | Feign Apache HttpClient |
| OpenAPI Feign version | 13.6 |
| Purpose | Communicate with the Fineract backend |

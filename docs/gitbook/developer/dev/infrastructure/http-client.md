# HTTP Client Library

## HTTP Client Library

The HTTP client library supports both OkHttpClient and Apache HttpClient 5.x configurations. The current Fineract client implementation uses OkHttp Client, which does not provide connection maxAge capability and requires custom workarounds. OkHttp introduces limitations in handling a large number of connections beyond a certain scale.

Apache HttpClient offers built-in connection lifecycle management including support for connection maxAge to avoid stale or long-lived connections. Properties for connection max age settings must be added, and connections must be closed after TTL expires.

A load balancing issue between the Fineract adapter and Fineract Read service occurs because kube-proxy does not recycle connections under steady traffic. The current OkHttpClient does not have an option to recycle connections.

Feign should be enabled with configuration Time-To-Live (TTL) for HTTP connection pools so connections are automatically refreshed to prevent stale connections to load-balanced endpoints. Configurable TTL for PoolingHttpClientConnectionManager must be implemented.

A new module based on the existing fineract-client module must be introduced where the generated Fineract client uses openFeign latest version 13.6. Services and model classes in the new module must be generated by OpenAPI, and OpenAPI generation must generate the feign library for the generated classes.

The new module must use Feign Apache HttpClient as the HTTP client implementation. Model and generated service APIs must match existing solutions with the same capabilities, request and response models must be the same as existing solutions, and exposed APIs and parameter list must be the same as existing solutions.

The generated fineract-client must be usable to communicate with the Fineract backend.

Upon receiving the SIGTERM signal, the application behaves as follows:

- It stops accepting new HTTP requests.
- It finishes any in-flight HTTP request.
- It stops accepting new partitions via JMS.
- It finishes any in-flight partitions before shutting down.

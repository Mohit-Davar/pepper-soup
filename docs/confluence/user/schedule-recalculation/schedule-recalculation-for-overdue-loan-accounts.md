# Schedule recalculation for overdue loan accounts

This enhancement introduces automated recalculation and regeneration of repayment schedules for loan accounts when instalments are not paid on their due dates, provided Interest Recalculation is enabled. The recalculation reflects the current balance, accrued interest, and the remaining repayment horizon, and it regenerates the future schedule so operations can proceed with accurate figures. This behavior applies only to accounts where the Interest Recalculation feature is enabled.
